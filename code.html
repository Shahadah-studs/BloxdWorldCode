World Codes for Bloxd.io

    Core Event Listeners (Callbacks)
  • onPlayerJoin(player): Triggers immediately when a user enters the lobby.
  • onPlayerLeave(player): Tracks when a player disconnects or quits.
  • onPlayerChat(player, message): Monitors text chat; crucial for setting up custom command prefixes (like !spawn or !tp).
  • onPlayerChangeBlock(player, blockX, blockY, blockZ, oldBlock, newBlock): Triggers when a player places or breaks a block.
  • onRespawnRequest(player): Intercepts the moment a player dies or requests a reset.
  • tick(): Runs continuously on every single server frame. Used for timers, zones, and real-time game loops.
