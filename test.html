Commands

Here you'll find secret and popular commands

      Popular commands
  • /help: Lists general chat commands.
  • /ownerhelp: Shows world owner administrative commands.
  • /tp pos [x] [y] [z]: Teleports you to specific coordinates.
  • /defaultgamemode [gamemode]: Changes default mode for future players.
  • /gamemode [gamemode] [username]: Changes a specific player's game mode.
  • /setspawn: Sets the global spawn point at your location.
  • /toggleopen: Toggles public lobby listing status.
  • /description [desc]: Adds a description to your world.
      World Builder Commands
  • //pos1: Registers the first corner coordinate of a regional structural box.
  • //pos2: Registers the opposite corner coordinate of a regional structural box.
  • //set [block_name]: Instantly Fills the entire designated area with a chosen block type.
  • //replace [old_block] [new_block]: Changes all specified blocks in an area without disturbing other assets.
  • //copy: Clones the designated structure area directly to your virtual clipboard.
  • //paste: Places the copied structural asset directly onto your character's current position.
  • //schematic save [name]: Exports a completed build region into a hard drive file.
  • //schematic load [name]: Imports a previously exported template file back onto the server grid.
