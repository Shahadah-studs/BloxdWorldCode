Commands

Here you'll find secret and popular commands

      Popular commands
  • /help: Lists general chat commands.
  • /ownerhelp: Shows world owner administrative commands.
  • /tp pos [x] [y] [z]: Teleports you to specific coordinates.
  • /defaultgamemode [gamemode]: Changes default mode for future players.
  • /gamemode [gamemode] [username]: Changes a specific player's game mode.
  • /setspawn: Sets the global spawn point at your location.
  • /toggleopen: Toggles public lobby listing status.
  • /description [desc]: Adds a description to your world.
      World Builder Commands
  • //pos1: Registers the first corner coordinate of a regional structural box.
